## Project Title  
**Network Performance Analysis using NetSim Lite**

---

## Project Description  
This project focuses on simulating and analyzing computer network performance using **NetSim Lite**.  
The simulation aims to study key performance metrics such as **throughput**, **latency**, **jitter**, and **packet loss** under varying network configurations and traffic conditions.  
By experimenting with different topologies and protocols, the project helps in understanding the efficiency and reliability of data transmission in real-world network scenarios.

---

## Technology Stack  
- **Programming Language:** C / C++ (for simulation scripting, if applicable)  
- **Frameworks/Libraries:** NetSim Lite built-in modules  
- **Tools:** NetSim Lite (by Tetcos)

---

## Setup Instructions  
1. Install **NetSim Lite** on your system.  
2. Launch the application and create a new project workspace.  
3. Choose the network topology (e.g., LAN, WAN, MANET, etc.) based on the experiment objective.  
4. Configure devices, links, and traffic sources as required.  
5. Run the simulation to capture performance metrics.  
6. Analyze results for parameters like **throughput**, **delay**, **packet delivery ratio**, and **jitter**.  
7. Export graphs and logs for documentation and analysis.

---

## Expected Outcome  
- Better understanding of how different protocols and topologies affect network performance.  
- Visualization of simulation data through NetSim’s analysis tools.  
- Identification of optimal configurations for efficient data communication.
